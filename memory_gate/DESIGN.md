# Same-model recurrent-memory sensitivity gate

This diagnostic follows the completed fresh-document assay. It does not revise that assay's frozen decision. It asks whether the original checkpoint's recurrent R/S tensors, built from 12,288 rather than 1,024 nested history tokens, improve teacher-forced prediction when the original checkpoint's weights and 12,288-token attention KV are held fixed. The saved 96 target IDs and two positions in each of six books are unchanged. Books, not spans or tokens, are the six uncertainty units.

For each 12K destination, import three partial states in a single pinned-Prism comparison: its own 12K state (identity), its own 1K state as saved, and an exact copy of that 1K state with only the serialized recurrent-cell position changed from 1,023 to 12,287. The pinned sequence-state header has little-endian fields magic `0xaf143cd8`, source sequence ID 0, recurrent cell count 1, cell position, and sequence-ID count 0 at byte offsets 0, 4, 8, 12, and 16. The rebased copy preserves every R/S tensor byte. Original attention KV stays in the 12K destination. The first target NLL is computed before import and is excluded from the effect.

Technical gates, all required before interpretation: all source and executable hashes match the freeze; each comparison's direct 96-token vector and own-12K import match the prior independent reference within 0.0001 nat/token; every A–B–A restore matches direct within 0.0001; raw-1K and position-rebased-1K imports match each other within 0.0001 on every affected target; the raw import produces exactly one expected non-consecutive-position warning and the rebased import none; the target-0 value is unchanged by construction. Any failure is a technical stop. The rebased 1K state is used for the effect estimate, with the raw state retained as an invariance control. The source files are never modified.

For affected targets 1–16, compute in each span the mean `NLL(1K R/S; 12K KV) − NLL(12K R/S; 12K KV)`. Average two spans per book, then six books. Positive means useful information older than 1K was present in the original recurrent state under this fixed attention context. The prespecified primary gate reports the six-book mean and two-sided 95% t interval (df 5); support for a practically detectable effect requires mean at least **+0.005 nat/token**, lower interval bound above zero, and at least five of six book means positive. An upper interval bound below +0.005 excludes an effect that large in this assay; otherwise the gate is unresolved. The same calculation on targets 1–95 is secondary and cannot override the primary gate. These thresholds classify sensitivity in these prose spans, not universal recurrent-memory utility.

If the primary gate supports recurrent benefit, the next experiment should separate S-only from R-only contributions with identities and restoration, then compare alpha/MLP variants under a fixed destination on fresh positions. If it excludes the declared benefit, stop the ordinary-prose state-import line and consider a separate remote-dependent retrieval task. An unresolved result calls for more independent documents or a better-targeted task, not a perturbation matrix. Do not treat a position-rebased-state failure as evidence for or against the gate hypothesis.
