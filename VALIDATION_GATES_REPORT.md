# Bonsai 2 validation gates: outcome and next work

The subsequent reciprocal-state controls and four-registry margin extension are complete in the [follow-up decision](VALIDATION_GATES_FOLLOWUP.md). The next-step list below records the plan at the time of this initial report.

The [pre-run design and status note](VALIDATION_GATES_PLAN.md) documents the scorer, dose-calibration, retrieval-pilot, and held-out results that led to these gates. **Both small validation gates passed their stated feasibility/identity criteria.** Neither gate establishes recurrent-state accumulation or rescues the failed held-out matched-dose comparison. No new perturbation matrix was run.

## Gate A — state save/restore and cross-checkpoint import

The [state freeze](validation_gates/state_transplant/STATE_GATE_FREEZE.json) fixes the first scorer-manifest book (Pride and Prejudice), position 30,000, histories 1,024 and 12,288, 96 identical target IDs, the original checkpoint, alpha seed 20260929, the state-gate source/executable and dynamically linked Prism CUDA library hashes. The program prefills all history IDs in the validated 512/512 batches. Target 0 is scored from the last history logit, and state is saved after that prefill; an imported state can influence only target positions 1–95 after gold target 0 is decoded. The hybrid-memory `PARTIAL_ONLY` flag serializes recurrent memory while leaving destination attention KV in place.

All four same-model captures (original/alpha × 1K/12K) had **zero maximum per-token NLL difference** between direct scoring, full-state roundtrip, and recurrent-only overlay on a restored full state. The direct scores also matched the existing position scorer exactly. The original and alpha recurrent-only state files were each 156,894,364 bytes. Full-state files grew from 224,024,108 bytes at 1K to 962,446,892 bytes at 12K. The [gate summary](validation_gates/state_transplant/gate_summary.json) records file hashes and every identity difference.

After those controls passed, importing alpha's recurrent-only state into the original-model context succeeded at both lengths. Original-model direct reruns remained exactly equal. On this **single book and seed**, transplanted-minus-original mean NLL was −0.004357 nat/token at 1K and −0.011467 at 12K, with target 0 unchanged by construction. The more negative 12K value is an exploratory observation, not an estimate of a population effect or evidence that alpha improves recurrent memory. Source checkpoint readout, attention KV, state compatibility, and document-specific effects still need controlled decomposition.

The first implementation is preserved in [attempt_v1](validation_gates/state_transplant/attempt_v1/). It saved state before the final history token. Its same-model full and partial roundtrips were exact, but its direct score differed from the original scorer by up to 0.064172 nat/token because it changed the 512-token decode boundaries. The runner stopped before cross-model import. The corrected freeze and source keep the original batch boundaries and eliminate that discrepancy. Reproduction: `bash analysis/bonsai2/validation_gates/state_transplant/build.sh`, `python3 analysis/bonsai2/validation_gates/state_transplant/freeze.py`, then `python3 analysis/bonsai2/validation_gates/state_transplant/run.py` on host CUDA.

## Gate B — gold-versus-wrong answer likelihood

The [answer-margin freeze](validation_gates/answer_margin/ANSWER_MARGIN_FREEZE.json) fixes one registry, question 1, base/swap counterparts, and short-near/long-near/long-far layouts. For each of six prompts, the scorer evaluates the gold and other queried entry's code, both with and without the target registry entry. Candidate sequences include the full code and GGUF end-of-turn token. All 24 candidate continuations use **nine target IDs**. Full-string tokenization preserves every rendered chat-prefix ID; frozen prompt token counts match the earlier server counts. The [raw NLLs and analysis](validation_gates/answer_margin/) retain each candidate's nine per-token scores.

The original-model gold-minus-wrong log-likelihood margin was positive on **6/6** present-target prompts; the base/swap prompts reverse which code is gold. Removing the target entry reduced the margin by at least 1 nat on **6/6**. Mean margin changed from **+12.665** to **−9.767** nats. The predeclared [baseline gate](validation_gates/answer_margin/baseline_gate.json) passed. The frozen one-seed alpha and MLP check also kept 6/6 present-target margins positive and 6/6 removal drops: mean present margin **+12.567** (alpha), **+12.788** (MLP), versus +12.665 original. See the [variant summary](validation_gates/answer_margin/variant_summary.json). This gives a sensitive score beneath exact-answer accuracy, but these six related prompts and one seed show no clear alpha-specific retrieval loss.

Reproduction: `python3 analysis/bonsai2/validation_gates/answer_margin/freeze.py`, run `python3 analysis/bonsai2/validation_gates/answer_margin/run.py baseline` on host CUDA, then `python3 analysis/bonsai2/validation_gates/answer_margin/analyze.py`. If the baseline gate passes, run `python3 analysis/bonsai2/validation_gates/answer_margin/run.py variants` and analyze again. The runner verifies frozen model, patch, prompt, scorer, and candidate-ID hashes before inference.

## Next planned steps

1. **Turn state-import feasibility into a controlled mechanism assay.** Add reciprocal original-state→variant-readout imports, same-model A–B–A restores, and a control that transplants full state versus recurrent-only state. Include a deliberate recurrent-memory positive control and verify it changes the assay in the expected direction. Freeze a fresh set of independent documents/spans and a smallest meaningful state-mediated contrast before treatment scoring. The one-book negative NLL values above must not guide dose selection.
2. **Expand answer-margin validity before a retrieval treatment study.** Test more independent registries and questions, preserve base/swap and target-removal controls, and verify a baseline distribution with room to move. Then freeze treatment arms/seeds and compare near/far margins at matched prompt length. Keep accuracy as a companion outcome; it remains at ceiling here.
3. **Only then reconsider a natural-text matrix.** Broaden calibration on new documents, require out-of-sample short-dose equivalence at a precision the sample can resolve, use fresh unseen books with multiple target spans, and predeclare power and thresholds. Do not retune on the existing four held-out books. Any positive behavioral result still needs state-specific controls to support a recurrent-state mechanism claim.

Host-device execution is needed for CUDA because the default sandbox hides `/dev/nvidia*`. The old frozen inputs and unrelated `.gitignore` and `uv.lock` changes were preserved.
