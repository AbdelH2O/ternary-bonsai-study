# Bonsai 2: measurement status and next validation gates

## Current status (before these gates)

The pinned Prism 842b188 sparse scorer passed next-token alignment, exact target-ID identity under nested 1K/4K/12K histories, document reset, logical-batch persistence, and a repeated original-model run. Its physical microbatch is fixed at 512/512. The corrected retrieval prompts passed shortcut and value-swap audits. Natural-text dose calibration on four separate books selected three alpha-only and three MLP-control perturbation seeds with similar **calibration-set means** near +0.005 nat per token at 1K. The original retrieval baseline was 48/48 exact; a balanced pilot of the six variants was 144/144 exact, so answer accuracy was saturated.

The treatment-held-out natural-text comparison scored four books at the same 96 target IDs across all histories and arms. The original-model rerun was bitwise equal. Its primary alpha-minus-MLP 12K-versus-1K excess NLL interaction was −0.000506 nat/token, with a document/seed bootstrap interval [−0.007116, +0.005787]. The held-out 1K excess means were +0.003026 (alpha) and +0.007664 (MLP), failing the frozen ±0.003 dose-match tolerance. The predeclared support gate therefore failed. This is no positive evidence for the proposed long-history gate-specific loss at these doses, but it does not exclude the +0.005 threshold. Four books with one target span each and three perturbation seeds are the independent units; the thousands of repeated token scores are not independent observations. See [scorer validation](scorer/VALIDATION_REPORT.md), [dose calibration](dose_calibration/DOSE_CALIBRATION_REPORT.md), [retrieval pilot](dose_calibration/PERTURBED_RETRIEVAL_PILOT_REPORT.md), and [held-out report](heldout_nll/HELDOUT_REPORT.md).

Independent read-only Astra and Fable reviews agreed that another broad matrix is premature. Astra reproduced the central arithmetic and cautioned that matching means on calibration is not equivalence on unseen text. Fable emphasized the low power of the four-book comparison and proposed direct recurrent-state transplantation. Their disagreement over whether the held-out dose gap is systematic does not change the frozen gate: the realized gap exceeded its limit. The reviews also noted that a permanent weight perturbation changes both state updates and readout, so a length contrast alone does not isolate state accumulation.

## Gate A: state save/restore identity and transplantation feasibility

Use the pinned Prism library and one original/one selected alpha checkpoint on a small frozen document/history fixture. Save state after the **full history prefill in the scorer's original 512-token boundaries**; target 0 is scored from the final history logit before transplantation, while imported state can affect targets 1–95 after decoding gold target 0. Score the continuation directly and after a full-state save/load. Repeat for the variant. On top of a restored full state, save/load its recurrent-only component and verify the same-model continuation again. A cross-model recurrent-only import is exploratory until those controls pass. Keep the attention KV from the destination checkpoint and replace only recurrent state, then compare with direct continuation. Record per-token NLL, state-file hashes/sizes, model hashes, context/sequence flags, and binary/library hashes. The first, preserved attempt saved state one token earlier; its changed batch boundary produced a 0.064 nat maximum per-token difference from the validated scorer despite exact internal roundtrips, so it was stopped before cross-model import.

**Identity gate:** identical model, history IDs, and continuation IDs must reproduce per-token NLL to the deterministic 512/512 floor (target maximum difference ≤0.0001 nat), and direct scores must match the validated original scorer at the same tolerance. A failed full or recurrent-only roundtrip stops mechanistic interpretation and triggers a runtime/API audit. A successful cross-model load is merely feasibility; it is not itself evidence of state-mediated loss. Negative/positive controls and more independent spans are required before estimating a mechanism effect.

## Gate B: teacher-forced gold-versus-wrong answer margin

Start with a frozen balanced subset of corrected retrieval prompts: one registry, one question, base/value-swap counterparts, and short-near/long-near/long-far layouts. Score both the gold code and the other queried entry's code under the exact GGUF-rendered chat prefix. Verify server prompt token counts and token-ID prefix identity, score the first answer token from the final prompt token, and handle candidate completion length and EOS explicitly. Use the original model first; add one alpha and one MLP variant only after original-model alignment and swap tests pass. Retain both candidate NLL vectors and report a gold-minus-wrong log-likelihood margin, with raw answer accuracy and candidate token counts alongside it.

**Validity gate:** original-model gold margin must be positive on every base and swapped counterpart and follow the code swap; a negative control with the target association removed or replaced must materially reduce or reverse the margin. A scorer/server disagreement, candidate tokenization mismatch, or failed negative control stops the assay. A positive margin with all greedy answers correct shows sensitivity, not recurrent causation.

## After the two gates

If Gate A works, use a fresh, larger set of independent text spans for state-mediated contrasts, with same-model state controls and an attention-state control. If Gate B works, extend the margin to more registries and include target-removal and swap controls before treatment comparisons. If either assay is insensitive, do not enlarge it by merely adding matrix cells. A future natural-text dose comparison needs broader calibration, an equivalence rule that accounts for uncertainty, fresh unseen documents with multiple spans, and a threshold/power calculation frozen before treatment scoring. Do not retune on the existing four held-out books. Preserve the frozen old inputs and unrelated working-tree changes.
