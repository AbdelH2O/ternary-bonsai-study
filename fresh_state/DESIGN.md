# Fresh-document recurrent-state assay: preregistered design

This assay tests whether an alpha-perturbed checkpoint's **recurrent state**, placed into the original checkpoint's readout and attention-KV context, causes more extra predictive loss after 12,288 than after 1,024 history tokens, relative to a fixed MLP perturbation. It tests permanently changed weights during state construction, not numerical precision of runtime F32 state storage. Cross-checkpoint state may be off the receiver's normal trajectory; even a positive result would need replication and compatibility checks before a causal gate claim.

The sources are six Project Gutenberg books not used in earlier calibration, held-out natural text, or the state method pilot: *Emma* (#158), *Little Women* (#514), *Wuthering Heights* (#768), *The War of the Worlds* (#36), *The Count of Monte Cristo* (#1184), and *Middlemarch* (#145). Each has fixed target starts at token positions 30,000 and 50,000. The two 12K histories and 96-token targets do not overlap. Each span uses exactly the same 96 gold target IDs under nested 1,024 and 12,288 history IDs. Tokenization is the pinned Prism GGUF tokenizer with no BOS or chat parsing. The original, alpha seed 20260929, and MLP seed 20260929 checkpoints and their hashes are frozen before inference. The 512/512 batch profile, 16,384 context, F16 attention KV, and pinned Prism libraries match the validated scorer.

Run four phases, stopping if a prerequisite gate fails:

1. **Independent direct reference.** Score all 24 span/history cases with the sparse position scorer for each checkpoint. Its raw 96-token NLL vectors are the reference for every later direct score.
2. **Same-model identity.** Capture full and recurrent-only state after prefill for every checkpoint/case. Direct, full roundtrip, and recurrent-only overlay must each agree with the reference at maximum per-token NLL difference ≤0.0001 nat. All 72 cases must pass before cross-checkpoint imports.
3. **Positive sensitivity control.** With the original model as destination, import recurrent-only state from the *next* book in the six-book cycle at the same target position and history length. Mean absolute NLL change on targets 1–95 must be ≥0.01 nat/token in all 24 controls. The first target is unaffected by construction. Every A–B–A restored continuation must agree with direct scoring within 0.0001 nat/token. All controls must pass before treatment imports.
4. **Treatment comparisons.** On each case, import alpha and MLP recurrent-only and full state into original destination, and original recurrent-only and full state into alpha and MLP destinations. Verify direct-score identity, target-0 identity, state-source hashes, and A–B–A restores for every condition. The 95 affected target tokens are averaged within a span; the two spans are averaged within a document. The six documents are the independent analysis units.

The primary contrast on each span is

`I = (Δalpha,12K − Δalpha,1K) − (ΔMLP,12K − ΔMLP,1K)`,

where `Δarm,h` is mean NLL after importing that arm's recurrent-only state into the original destination minus the original destination's direct NLL, over targets 1–95. Positive `I` is the proposed extra alpha-specific long-history state loss. The smallest meaningful contrast is fixed at **+0.005 nat/token**, inherited from the earlier natural-text hypothesis threshold. A 20,000-replicate document-cluster bootstrap with seed 20260929 gives percentile 95% intervals. Support requires a point estimate ≥+0.005, a 95% lower bound >0, and at least five of six document means >0. An upper bound <+0.005 excludes an effect of that size in this assay. Otherwise the result is unresolved; technical-gate failure means no treatment interpretation.

Short-history dose comparability is a separate qualification: report the mean `Δalpha,1K − ΔMLP,1K` and its document-bootstrap 90% interval. Only call a positive interaction **alpha-specific at comparable short-state dose** if that entire interval lies within ±0.003 nat/token, the earlier frozen dose tolerance. Without this equivalence, report a directional treatment contrast but no gate-specific attribution. Secondary analyses are alpha-only and MLP-only long/short changes, full-versus-recurrent imports, reciprocal destinations, per-document signs, and baseline long-history benefit. They cannot override the primary decision rule.

The documents are fresh to this analysis, not guaranteed absent from model training. Gold target continuation provides up to 95 preceding target tokens, so this assay measures state influence on predictive loss rather than retention of a particular fact. No new perturbation seeds or weight matrices will be created for this test. All source files, token IDs, executable/model/library hashes, raw NLLs, state-file hashes, and phase gates will be retained.
