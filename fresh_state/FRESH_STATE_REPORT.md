# Fresh-document recurrent-state assay: result and decision

The [preregistered design](DESIGN.md) and [freeze](FRESH_STATE_FREEZE.json) fixed six Project Gutenberg books that were absent from all prior Bonsai 2 calibration, held-out natural-text, and state-method fixtures: [*Emma*](https://www.gutenberg.org/ebooks/158), [*Little Women*](https://www.gutenberg.org/ebooks/514), [*Wuthering Heights*](https://www.gutenberg.org/ebooks/768), [*The War of the Worlds*](https://www.gutenberg.org/ebooks/36), [*The Count of Monte Cristo*](https://www.gutenberg.org/ebooks/1184), and [*Middlemarch*](https://www.gutenberg.org/ebooks/145). Each contributed two disjoint target spans at token positions 30,000 and 50,000, with identical 96-token continuations under nested 1,024/12,288 histories. The checkpoint set was the existing original model, alpha seed 20260929, and MLP seed 20260929; no new perturbation matrix was made.

**All technical gates passed before treatment interpretation.** Independent [direct reference scores](reference_gate.json) were frozen for 24 span/history cases per checkpoint. All **72** same-model state captures matched those references exactly, both as full-state roundtrips and as recurrent-only overlays; the [capture gate](capture_gate.json) reports zero maximum per-token NLL difference throughout. The **24** unrelated-book recurrent-state controls all exceeded the preregistered 0.01 nat/token mean-absolute sensitivity floor; their minimum was **0.4906**. All **72** treatment destination/history comparisons had exact direct-reference and A–B–A restoration, with target 0 unchanged. The [positive gate](positive_gate.json), [treatment gate](treatment_gate.json), and per-case JSON files retain the raw 96-token NLL vectors and state hashes. The original model benefited from longer history by **0.1334 nat/token** on average over targets 1–95, with a positive document-mean benefit in all six books.

The primary contrast asks whether alpha recurrent state imported into the original model causes more 12K-versus-1K loss than MLP recurrent state imported into that same model. It averages targets 1–95 within each span, two spans within each document, then six documents. Positive values would support the proposed extra alpha long-history loss.

| Book | Alpha-minus-MLP long/short state interaction, nat/token |
|---|---:|
| Emma | −0.006029 |
| Little Women | +0.006951 |
| Wuthering Heights | +0.000516 |
| The War of the Worlds | −0.000091 |
| The Count of Monte Cristo | +0.001616 |
| Middlemarch | −0.005653 |
| **Six-book mean** | **−0.000448** |

The predeclared 20,000-replicate document bootstrap 95% interval is **[−0.003823, +0.003028] nat/token**. Three document means are positive and three negative. Under the frozen rule, the upper bound falls below the proposed **+0.005 nat/token** meaningful effect, so that strong effect is **excluded within this assay**. The result does not support alpha-specific extra long-history damage; it does not rule out smaller effects or different tasks, perturbations, or models. The [analysis summary](analysis_summary.json) contains every span effect and the deterministic bootstrap output. An independent recomputation directly from the comparison JSONs reproduced the −0.000448 mean; leaving out one book moves the mean only between −0.001928 and +0.000668.

Short-history **dose equivalence was not established**: `Δalpha,1K − ΔMLP,1K = −0.002940` nat/token, with document-bootstrap 90% interval **[−0.004846, −0.001240]**. The interval extends below, but overlaps, the frozen ±0.003 equivalence band; failing this equivalence gate does not establish that the doses differ. On average, alpha recurrent-state import changed the original model's NLL by −0.000851 at 1K and −0.002720 at 12K; the MLP values were +0.002090 and +0.000668. The observed long/short changes were −0.001870 for alpha and −0.001421 for MLP. The reciprocal and full-state controls also depend on the receiving checkpoint and whether its attention KV is retained, so no clean gate-specific causal attribution follows from the state-swap signs.

**Decision:** the state assay is technically valid and sensitive on these spans, but this six-book result points against the preregistered +0.005 alpha-specific long-history state-loss prediction at the tested weights. Do not expand to a broad perturbation matrix on this evidence. The +0.005 threshold and ±0.003 dose band were inherited from the earlier natural-text study; they were declared before this run, but their practical meaning for an imported-state estimand has not been independently calibrated. The cross-checkpoint import is an intervention on potentially off-trajectory states, and the weights were permanently altered while the runtime recurrent cache remained F32. This tests a bounded state-mediated predictive-loss contrast, not whether quantization caused the shipped model's quality gap or whether a particular fact survives 12K tokens. Six books are still a small number of independent units; the bootstrap replicates do not create more data.

Reproduce in order with `python3 analysis/bonsai2/fresh_state/freeze.py`, then `python3 analysis/bonsai2/fresh_state/run.py reference`, `capture`, `positive`, `treatment` on host CUDA, followed by `python3 analysis/bonsai2/fresh_state/analyze.py`. The runner checks the pinned program, model, library, document, token-ID, and state hashes before each phase. The old frozen inputs and unrelated `.gitignore` and `uv.lock` changes were left untouched.
