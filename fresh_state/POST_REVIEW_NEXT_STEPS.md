# Independent review and next validation gate

This is a post hoc review of the completed [fresh-document assay](FRESH_STATE_REPORT.md), not a change to its [frozen design](DESIGN.md), data, or decision rule. It is separate from the 678-file frozen artifact inventory. Astra and Fable independently read the raw comparisons and pinned runtime; neither edited the repository or ran inference.

Both reproduced the six-document primary mean of **−0.000448 nat/token** and the frozen bootstrap interval **[−0.003823, +0.003028]**. The preregistered exclusion of a **+0.005** mean effect holds for this fixed state-import assay. Its strength is limited: a six-document t interval is about **[−0.00555, +0.00466]**, excluding +0.005 only narrowly. There is one perturbation seed per arm, and the document bootstrap does not measure seed variation. The 90% short-state dose interval **[−0.004846, −0.001240]** overlaps but is not wholly inside ±0.003; equivalence was not established, and non-equivalence was not proved. The [report](FRESH_STATE_REPORT.md) was corrected on that wording, with its artifact-inventory entry updated.

The central unresolved issue is whether the 1K-to-12K gain in ordinary prose depends on recurrent state at all. The original checkpoint gains **0.1334 nat/token** from longer history, but its retained attention KV could supply that gain. The current “recurrent-only” import includes both convolution memory **R** and DeltaNet state **S**, and its unrelated-book control changes recent context as well as remote information. Cross-checkpoint imports also place donor states under receiver weights and may be off the receiver's trajectory. Reciprocal imports show receiver dependence; they do not provide an additive decomposition of damage into “state” and “readout.” The 95-token frozen mean can hide a short-lived effect: early imported-state changes and later changes have different signs. These observations motivate a new diagnostic; they do not alter the frozen result.

## Next gate, before any new perturbation matrix

1. **Validate the cross-history import method on CPU.** In the pinned Prism implementation, importing a 1K recurrent state into a destination with 12K attention KV also imports the recurrent cell's source position. Continuation logs a non-consecutive-position warning. Inspect the serialization and establish whether position metadata affects the numerical state or only bookkeeping. Specify the expected warning, state-source hashes, target-0 handling, same-model 12K identity, and A–B–A restoration checks before GPU work. Any ambiguity that changes predictions under position rebasing is a technical stop.
2. **Freeze and run a small original-model memory gate using the existing 12 spans and captures.** Prefill the original model with each 12K history, retain its 12K attention KV, and compare its own 12K R/S state with its own 1K R/S state built from the nested suffix. This holds receiver weights and attention context fixed. Define memory benefit as NLL with the 1K state minus NLL with the 12K state, averaging the two spans within each of six books. Prespecify affected targets **1–16** as the early diagnostic and **1–95** as the continuity check, with document-level uncertainty and a numerical go/no-go threshold frozen before inference. Same-model self-import must reproduce direct scoring within 0.0001 nat/token and restoration must pass. This is a sensitivity gate on these natural-text spans, not a proof about all long-context tasks.
3. **Only if recurrent benefit is reliably positive, isolate the mechanism and treatment.** Separate S-only and R-only imports with roundtrip identities and restoration, then compare alpha, MLP, and original 1K-versus-12K state benefits within a fixed destination. A common destination reduces readout variation, but does not automatically cancel cross-checkpoint incompatibility. Require a second existing perturbation seed and fresh positions or documents before claiming a general alpha effect. A remote-information task with an identical recent suffix is the next test if ordinary prose fails to reveal recurrent dependence or if the mechanism remains ambiguous.

If the original-model memory gate is null, stop the ordinary-prose state-import line and report its detection limit; do not infer that recurrent memory is never useful. If it is positive but alpha and MLP reduce it equally, that is nonspecific damage. If alpha uniquely reduces a demonstrated recurrent benefit, proceed to an independently frozen replication. More documents alone cannot resolve R/S mixing or receiver-state compatibility.

Fable proposed adding starts at 70K and 90K in the existing books after a positive gate. That yields **at most 23 total spans** (the current 12 plus ten in five long books and one 70K span in *The War of the Worlds*), not 36; the six books remain the uncertainty clusters, so no 36-independent-span standard-error forecast should be used. The position and length assumptions need verification against the frozen token files before any extension.
