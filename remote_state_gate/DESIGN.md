# Remote-value recurrent-state sensitivity gate

Use the previously CPU-audited corrected retrieval registries **08–15**, which were not used in the earlier accuracy or answer-margin inference. For each registry, use question 1 in the `long-far` layout, with the base and value-swapped counterparts. Only the two queried records' remote code values change. The rendered chat question and last 1,024 token IDs must be identical between counterparts, while their gold and wrong code identities reverse. Score the complete code plus end-of-turn as nine teacher-forced target IDs under the pinned GGUF chat template. The same two candidate strings and token counts must be used on both sides of each swap. No new weight variant is involved.

The **baseline gate** scores both candidate codes for each of 16 prompts on the original checkpoint. Gold-minus-wrong log-likelihood margin must be strictly positive in all 16. A failure stops state interpretation: the baseline has not demonstrated use of the remote assignment on these fresh cases. The counterfactual value swap and identical recent suffix are the shortcut controls; both margins must follow the swapped answer. The earlier 04–07 margin results are background only and cannot enter the eight-registry estimate.

If baseline passes, capture the original model's full and recurrent-only states after each of the 16 chat prefixes. Direct, full roundtrip, and recurrent-only roundtrip must agree with the independent baseline gold-score vector within 0.0001 nat at every token. Then, for each destination prompt and each of its two candidate codes, retain the destination's attention KV and original weights while importing either its own recurrent R/S state or its value-swapped counterpart's R/S state. The two source states have the same cell position; no non-consecutive-position warning is expected. Direct, own-state identity, and every A–B–A restore must match within 0.0001 nat/token; target 0 is computed before import and excluded as an import check. State hashes, candidate IDs, and all 16 source mappings must match the freeze. Any technical failure stops interpretation.

For each destination, `margin = log P(gold complete code) − log P(wrong complete code) = sum NLL(wrong) − sum NLL(gold)`. The primary state effect is `own-state margin − counterfactual-state margin`. Average base and swapped destinations within each registry, then average the eight registry effects. Positive means its own remote-value recurrent state favors the correct association more than the counterfactual state under the same destination attention KV. A two-sided 95% t interval uses the eight registry means (df 7). Prespecified support requires mean at least **+0.5 nat per complete answer**, lower bound above zero, and at least six of eight registry means positive. An upper bound below +0.5 excludes an effect of that size in this assay; otherwise the decision is unresolved. Report each destination and registry, including sign reversals and candidate-specific changes. The baseline margin and total score changes are descriptive; they cannot override the primary rule.

This is a same-checkpoint mixed-state intervention: the destination's attention KV still encodes its own remote records, so attention may override or interact with the imported recurrent state. R and S are imported together, and a positive effect does not yet identify DeltaNet S. A null bounds this particular independent state influence at the frozen effect size; it does not show that recurrent memory lacks remote content. If support is obtained, separate S-only from R-only with new identity/restoration controls before any alpha/MLP treatment. No broad perturbation matrix follows directly from this gate.
